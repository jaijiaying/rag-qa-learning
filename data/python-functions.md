# Python 函数基础

来源：Python 官方教程
https://docs.python.org/3/tutorial/controlflow.html#defining-functions

函数是一段可以重复调用的代码。使用 def 关键字定义函数，函数名后面可以声明参数，函数体必须缩进。

函数可以使用 return 返回结果。如果没有写 return，函数默认返回 None。

参数可以设置默认值。调用函数时，如果没有提供这个参数，就会使用默认值。默认参数应该放在没有默认值的参数之后。

关键字参数通过参数名传值，例如 calculate_total(price=10, quantity=2)。关键字参数可以让调用代码更容易理解。

函数内部定义的变量通常是局部变量，只在函数内部有效。如果函数需要修改外部变量，应明确使用参数和返回值传递数据。

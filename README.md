# 阶段07｜企业级 RAG 问答系统（本地学习复现）

这是依据课程项目流程独立实现的可运行学习版本，不是课程源码。它用 Python 标准库实现：文档导入、段落切分、倒排检索、引用片段返回和问答 API，便于先验证完整链路。

## 运行

```bash
python3 server.py
```
打开 http://127.0.0.1:8097/ 。在页面粘贴文档并点击“建立索引”，再输入问题。系统会返回相关片段和来源位置。

## 对照课程的工程化替换点

- `ingest_text`：替换为 PDF/Word/Markdown 解析器。
- `chunk_text`：替换为按标题、段落和 token 数的切分策略。
- `retrieve`：替换为 embedding + 向量数据库（Milvus/pgvector/FAISS）。
- `answer`：替换为 LLM，并将检索片段放入上下文，要求答案带引用。
- 生产环境还需加入用户权限、文档版本、异步任务、日志、评测集和敏感信息过滤。
